Boutons

Aide

Téléporteur : place le bouton, puis clique la case d'arrivée — même couleur pour les deux.
Bouton destructeur : place le bouton, puis clique le glaçon qu'il doit détruire — même couleur pour les deux.
Un glaçon poussé sur un bouton l'active aussi, pas seulement un mammouth qui marche dessus — pousser un glaçon sur un téléporteur le gâche pour de bon.
Un mammouth seul pousse un glaçon isolé ; N glaçons collés demandent N mammouths alignés derrière, poussant ensemble.
Plusieurs sorties sont permises — rien n'empêche d'en bloquer certaines avec un glaçon dès le départ.

🎉 Tout le troupeau est sorti !
 

Règles

Tous les mammouths doivent atteindre une sortie. Clique un mammouth pour le sélectionner, puis utilise tes 4 touches de déplacement (personnalisables dans ⚙️ Réglages) ou un clic sur une case adjacente pour le déplacer.

Un mammouth seul pousse toujours un glaçon isolé d'une case dans le sens de son déplacement. Mais pour pousser N glaçons collés les uns aux autres, il faut N mammouths alignés juste derrière, qui avancent tous ensemble au même coup — c'est pour ça qu'il faut parfois se regrouper. Impossible si un mur ou un mammouth occupe la case où le glaçon devrait aller — certains glaçons ne peuvent jamais être poussés sans tout bloquer : c'est fait exprès, il faut trouver le bon bouton qui règle le problème autrement.

Un bouton s'active dès qu'un mammouth marche dessus ou qu'un glaçon est poussé dessus — attention, pousser un glaçon sur un téléporteur le gâche pour de bon (rien à téléporter), alors que pousser un glaçon sur un bouton destructeur peut être exactement le but recherché.

  • Sol — libre
  • Roche — infranchissable
  • Glaçon — se pousse d'une case (ou plusieurs collés, à plusieurs mammouths)
  • Sortie
  • 💥 Bouton destructeur — détruit le glaçon qui lui est lié, une fois
  • 🌀 Téléporteur — envoie le mammouth sur la case liée, une fois

Chaque bouton a sa propre couleur, partagée avec ce à quoi il est lié (case d'arrivée ou glaçon à détruire) — un pointillé les relie aussi, pour voir d'un coup d'œil ce qui se passera.
